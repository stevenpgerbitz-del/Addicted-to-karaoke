# Addicted to Karaoke — Future Updates

Notes for ideas that have been discussed but are **not approved for immediate implementation**. This file is planning-only; updating it does not change the website or app.

## Venue amenities

### Private Karaoke Rooms
- **Date noted:** November 18, 2026
- **Status:** Backlog — implement in a future venue amenities update
- **Request:** Add **Private Karaoke Rooms** as a selectable amenity for venue listings. Some karaoke venues offer rooms for private groups, rather than only an open public karaoke area.
- **Placement:** The existing venue Amenities selection tiles in Venue Management; show the amenity in public Venue Details when selected.
- **Notes for later:** Treat the amenity as an indication that a venue offers private karaoke rooms, *not* as a claim that a room is available to book at any particular time. Details such as room capacity, reservation requirements, and pricing can be considered in a later enhancement.
- **Scope:** Do not change the current live site, venue data, or wizard as part of recording this idea.
